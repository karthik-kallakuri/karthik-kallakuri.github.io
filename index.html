A security program with no licence bill

I designed and implemented this three-phase program on SquadSync's existing Azure DevOps pipeline, using open-source tools on self-hosted Linux agents. Each phase catches what the one before it can't.

  1. Phase 1: on every pull request

    PR security gate

    • GitleaksSecret scanning, as a hard gate
    • Bandit, SemgrepSAST for Python and TypeScript
    • CheckovHelm and infrastructure-as-code scanning
    • Ollama + DeepSeek-CoderLocal AI code review with inline findings
  2. Phase 2: at build time

    Container gate

    • HadolintDockerfile linting
    • TrivyBlocks the push to ACR on HIGH and CRITICAL findings
    • SyftCycloneDX SBOMs for supply-chain visibility
  3. Phase 3: in the cluster

    Runtime security

    • OPA GatekeeperAdmission control
    • FalcoRuntime threat detection as a DaemonSet
    • Network policiesLimits on pod traffic
    • OWASP ZAPDAST against running services
